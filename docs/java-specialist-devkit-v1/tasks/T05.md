## 实现步骤

1. 只取有明确源码范围的签名、直接注释、路由/statement/config key。
2. 同时保留wholeIdentifier和camel/snake拆分；中文连续字串+bigram不假装能理解英语业务。
3. secret值不写入SearchDocument；只允许安全key。方法body全文embedding不是默认实现。
4. 文档、postings、df与file hash一次事务更新；删除/rename同样撤销。
5. query结果返回具体declaration name/selection及匹配证据range；不能统一line1。
6. fixture反向测试注释说HALF_UP但代码DOWN：comment是发现线索，不覆盖程序事实。

## 关键代码/结构约束

下面是本卡需要实现的核心逻辑或结构示例，不是声称已经修改产品；需要放到所列文件并通过真实编译/集成。临时变量由当前消费者上下文提供，不能将示例当成独立可运行的完整产品补丁。

```typescript
export interface SearchDocument {
  documentId: string; declarationId: string; path: string; contentHash: string;
  representationVersion: 1;
  sourceKind: "signature"|"comment"|"framework-key";
  startLine: number; endLine: number; normalizedText: string;
}
export function searchDocumentId(d: Omit<SearchDocument,"documentId">): string {
  return [d.declarationId,d.sourceKind,d.startLine,d.endLine,d.contentHash,d.representationVersion].join("|");
}
```
