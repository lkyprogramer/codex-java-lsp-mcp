## 关键代码/结构约束

下面是本卡需要实现的核心逻辑或结构示例，不是声称已经修改产品；需要放到所列文件并通过真实编译/集成。临时变量由当前消费者上下文提供，不能将示例当成独立可运行的完整产品补丁。

```typescript
export class QueryWorkBudget {
  private used=0;
  constructor(readonly maxPostings: number, private readonly remainingMs: ()=>number) {
    if (!Number.isInteger(maxPostings) || maxPostings<1) throw new Error("invalid work limit");
  }
  take(): "ok"|"deadline"|"postings" {
    if (this.remainingMs()<=0) return "deadline";
    if (this.used>=this.maxPostings) return "postings";
    this.used++; return "ok";
  }
  visited(): number { return this.used; }
}
```
