## 实现步骤

1. stock zvec产品级对照先跑，确认存在A2没有的正确入口。
2. 有收益再对齐representation做lexical/dense/RRF消融。

4. exact与已知anchor不发embedding；故障回A2，无无限重试。
5. 只在GO_OPTIONAL后考虑主工程hook，其余情况KEEP_EXTERNAL/NO_GO/INCONCLUSIVE都可收口。
