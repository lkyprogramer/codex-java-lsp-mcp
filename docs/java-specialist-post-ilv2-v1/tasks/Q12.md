# Q12 · 删减、文档唯一入口与停止决定

**阶段：** P4  
**依赖：** Q11  
**实施属性：** 主线任务；模型/生产调用仍受独立授权

## 目标与边界

保持个人项目一条默认链，不让试验成为永久维护负担。

## 文件

README.md、docs/post-ilv2/、package.json中实际新增实验脚本、未被采用的试验模块；不删除历史raw与冻结测试。

文件路径按本包固定SHA核查或明确标为拟新增。执行前确认文件存在；旧文件改名时记录映射并跟随真实调用链，不创建重复模块。共享schema与symbol.ts接线由单一集成者合入。

## Interfaces

decision-log每方向ADOPT/NO_GAIN/INCONCLUSIVE/NOT_TRIGGERED；保留功能必须有一类验证任务及维护owner。

公共预算、view/proof和状态合同继承[05](../docs/05-contracts.md)；所有测试变量如report/summary由本卡实际fixture/函数结果生成，不能硬编码成预期答案。纯断言示例在现有Node test包中落地，assert使用`node:assert/strict`。

## RED / 控制断言

```ts
assert.equal(summary.defaultRetrievalImplementations,1);
assert.equal(summary.defaultEmbeddingDependencies,0);
assert.equal(summary.newLongRunningDaemons,0);
assert.equal(summary.publicToolNames.length,5);
```

对本来正确的既有行为，记录现有测试与补充边界，不修改代码强造RED。对新行为，测试应因缺失行为失败，而不是因为路径拼写/依赖装载失败。

## 执行步骤

- [ ] 固定本任务输入、阶段身份和允许改动；条件卡先审触发证据。
- [ ] 将上述断言和下列动作中的边界转为可运行定向测试，保存原失败/控制结果。
- [ ] 记录online non-test LOC净变化和被删除试验，不把移动目录当减少复杂度。
- [ ] 淘汰没有证据的备用ranker/第二scorer/未采用provider；稳定结果保留可重放配置和报告。
- [ ] README只解释query→outline/evidence→按需JDT三个能力，不要求先status或每次使用全部tool。
- [ ] 旧deep文档保留历史适用SHA，当前入口只指向本轮已采纳设计与状态。
- [ ] 明确下一轮是否值得继续；无净收益则停止，不自动再生成平台级路线。
- [ ] 运行定向验证；评测侧与公开wire侧都检查，不只看内部对象。
- [ ] 写result.json与命令/raw哈希；提交最小差异。阶段结束统一独立review，不每个小动作重跑全部Mac系统门。

## 最小验证

```bash
npm run measure:production-ts && npm run measure:tool-schema && git diff --stat
```

涉及拟新增文件/脚本时先创建并编译，再执行本命令；原生验证须在已授权Mac隔离checkout，不能在当前文档包目录运行。单测预期无fail/cancel；环境skip不得被计作本任务真实运行验证。

## 验收与停止

**验收：** 一个默认路径、无embedding/新daemon、文档与实际schema一致；所有未做事项有原因。

**停止：** 不要为了完成cleanup删除仍被生产引用的纯函数，先做实际依赖/测试检查。

**提交：** `docs(quality): close post-ilv2 decisions and retire unused experiments`

**报告：** 使用[任务结果模板](../templates/task-result.template.json)与[报告规则](../docs/12-reporting.md)，记录所有未测项。Task PASS不等于阶段PASS，更不等于生产部署授权。
