## Interfaces

公共预算、view/proof和状态合同继承[05](../docs/05-contracts.md)；所有测试变量如report/summary由本卡实际fixture/函数结果生成，不能硬编码成预期答案。纯断言示例在现有Node test包中落地，assert使用`node:assert/strict`。

## RED / 控制断言

```ts
assert.equal(classifyFailure({ discovered: true, declarationCorrect: true,
 relationAvailable: true, selected: true, rangeCovered: false, serialized: null,
 deliveryConfirmed: null, taskPassed: null }), "RANGE_MISS");
assert.equal(classifyFailure({ discovered: null, declarationCorrect: null,
 relationAvailable: null, selected: null, rangeCovered: null, serialized: null,
 deliveryConfirmed: null, taskPassed: null }), "UNMEASURED");
```

对本来正确的既有行为，记录现有测试与补充边界，不修改代码强造RED。对新行为，测试应因缺失行为失败，而不是因为路径拼写/依赖装载失败。
