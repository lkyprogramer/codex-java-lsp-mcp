## RED / 控制断言

```ts
const a={path:"A.java",contentHash:"h",startLine:10,endLine:20};
const b={path:"A.java",contentHash:"h",startLine:15,endLine:25};
assert.equal(marginalCoveredLines([b],[a]),5);
assert.equal(marginalCoveredLines([a],[a]),0);
assert.equal(marginalCoveredLines([{...a,contentHash:"other"}],[a]),11);
```

对本来正确的既有行为，记录现有测试与补充边界，不修改代码强造RED。对新行为，测试应因缺失行为失败，而不是因为路径拼写/依赖装载失败。
