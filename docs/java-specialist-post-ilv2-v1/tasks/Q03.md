# Q03 · 增加按需单文件outline

**阶段：** P1  
**依赖：** Q00（不依赖Q01/Q02：outline是纯投影，不消费receipt或归因结果）  
**实施属性：** 主线任务；模型/生产调用仍受独立授权

## 目标与边界

让Agent在正确文件内比较候选方法，不默认读整文件。

## 文件

新增 src/discovery/outline.ts/.test.ts；修改 src/tools/symbol.ts、对应tool/schema测试、src/mcp-server-factory.ts（只接现有tool）、必要的JavaFileBundle投影。不得改snapshot schema或构建全图。

文件路径按本包固定SHA核查或明确标为拟新增。执行前确认文件存在；旧文件改名时记录映射并跟随真实调用链，不创建重复模块。共享schema与symbol.ts接线由单一集成者合入。

## Interfaces

实现05§5.2 selectOutlineEntries与runOutline；outline的wire附现有indexView和public identity，不泄漏declarationKey。条目覆盖type/constructor/method/field；nearLine按“包含者优先、其余按距离”选取，输出恢复源码顺序（05§5.2）。

公共预算、view/proof和状态合同继承[05](../docs/05-contracts.md)；所有测试变量如report/summary由本卡实际fixture/函数结果生成，不能硬编码成预期答案。纯断言示例在现有Node test包中落地，assert使用`node:assert/strict`。

## RED / 控制断言

```ts
const entries = [
 { declarationKey:"m:a", kind:"method", name:"cancel", signature:"cancel(long)",
   startLine:10,endLine:15,selection:{line:10,column:17} },
 { declarationKey:"m:b", kind:"method", name:"cancel", signature:"cancel(String)",
   startLine:21,endLine:25,selection:{line:21,column:17} }
] as const;
const picked=selectOutlineEntries(entries,{limit:1,nearLine:23});
assert.equal(picked.entries[0].declarationKey,"m:b");
assert.equal(picked.omittedSymbols,1);
assert.equal(symbolNeedsJdt({operation:"outline"}),false);

// 大文件尾部nearLine：邻近声明不能被文件开头的方法挤掉
const many = Array.from({length:100},(_,i)=>({ declarationKey:`m:${i}`, kind:"method" as const,
  name:`op${i}`, signature:`op${i}()`, startLine:10*i+1, endLine:10*i+9,
  selection:{line:10*i+1,column:5} }));
const tail=selectOutlineEntries(many,{limit:8,nearLine:905});
assert.ok(tail.entries.some(e=>e.declarationKey==="m:90"));          // 包含nearLine
assert.ok(tail.entries.every(e=>Math.abs(e.startLine-905)<=60));     // 其余为最近邻
assert.ok(!tail.entries.some(e=>e.declarationKey==="m:0"));
assert.deepEqual(tail.entries.map(e=>e.startLine),
  [...tail.entries.map(e=>e.startLine)].sort((a,b)=>a-b));          // 输出为源码顺序
assert.equal(tail.omittedSymbols,92);

// 字段是outline条目（字段/接口影响工作流需要）
const withField=selectOutlineEntries([{ declarationKey:"f:status", kind:"field", name:"status",
  signature:"OrderStatus status", startLine:4, endLine:4, selection:{line:4,column:23} }],{limit:8});
assert.equal(withField.entries[0].kind,"field");
```

对本来正确的既有行为，记录现有测试与补充边界，不修改代码强造RED。对新行为，测试应因缺失行为失败，而不是因为路径拼写/依赖装载失败。

## 验收与停止

**验收：** 默认8最大20、wire≤4096B；同名不合并、nearLine包含者与最近邻都在、输出源码顺序；字段条目存在；source变化不READY；启动JDT次数0；工具名仍5。

**停止：** 4096B只放得下少数长ID时明确omit，不能删身份；不因此无限扩预算。
