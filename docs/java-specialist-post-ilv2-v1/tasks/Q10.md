# Q10 · 一次可信的真实Agent配对

**阶段：** P3  
**依赖：** Q01, Q02, Q04（G0只门控本卡的LIVE运行）  
**实施属性：** 主线任务；模型/生产调用仍受独立授权

## 目标与边界

证明新接口/证据改变的是任务结果或总成本，不只是工具payload。

## 文件

复用scripts/evaluate-java-task.mjs、ilv2-mac-paired-compare.mjs。仓库另有V5R/MAC-10时期的真实模型设施，本卡必须先审计再决定复用方式，不得绕开：

| 现有脚本 | 已有能力 | 本卡用法 |
|---|---|---|
| `scripts/run-agent-trace-live.mjs` / `run-agent-trace-matrix.mjs` | 经MCP stdio调用工具的live agent trace、usage合并、缺失usage不填0；当前只接java_impact，结果是path-coverage代理 | 优先扩展为可暴露java_symbol query/outline/evidence与原生read的两臂runner；任务结果仍由evaluate-java-task/oracle判定 |
| `scripts/openai-compatible-chat.mjs`、`live-model-profiles.mjs` | 模型调用、请求配置审计、usage提取 | 直接复用；Q01的最终请求receipt挂在这里的最终序列化body上 |
| `scripts/eval-pilot-compare.mjs` | 按身份校验的results pack比较、cluster bootstrap CI、prompt-token中位数 | 直接复用做两臂比较，不另写统计 |

审计结果写入result.json（逐脚本：复用/扩展/不适用及原因）。只有现有runner无法以薄改动满足两臂对称与receipt要求时，才新增scripts/ilv2-quality-pilot.mjs/.test.mjs；它也只做编排，不复制scorer、模型客户端或统计。

文件路径按本包固定SHA核查或明确标为拟新增。执行前确认文件存在；旧文件改名时记录映射并跟随真实调用链，不创建重复模块。共享schema与symbol.ts接线由单一集成者合入。

## Interfaces

新CLI：node scripts/ilv2-quality-pilot.mjs --manifest ABS_JSON --out ABS_NEW_DIR [--allow-model-calls]；无授权只校验并输出UNMEASURED，不发请求。manifest含完整schedule与已授权backend，不默认latest model。

公共预算、view/proof和状态合同继承[05](../docs/05-contracts.md)；所有测试变量如report/summary由本卡实际fixture/函数结果生成，不能硬编码成预期答案。纯断言示例在现有Node test包中落地，assert使用`node:assert/strict`。

## RED / 控制断言

```ts
const summary = summarizeSchedule([
 {slotId:"a",state:"COMPLETED",passed:true,usage:null},
 {slotId:"b",state:"TIMED_OUT",passed:false,usage:null}
]);
assert.equal(summary.scheduled,2);
assert.equal(summary.successful,1);
assert.equal(summary.endToEndSuccessRate,0.5);
assert.equal(summary.providerUsage,null);
```

对本来正确的既有行为，记录现有测试与补充边界，不修改代码强造RED。对新行为，测试应因缺失行为失败，而不是因为路径拼写/依赖装载失败。
