# Q09 · 只优化已测重复等待与source I/O

**阶段：** P2  
**依赖：** Q00, Q04  
**实施属性：** 条件任务，先写触发证据；无触发记录NOT_TRIGGERED

## 目标与边界

减少用户实际等待，不再为几毫秒启动一次底座重构。

## 文件

优先仅测src/jdtls-session.ts、jdtls-first-touch.ts、evidence-source-reader.ts；代码变化限定在确证的重复导入/读取处，不动owner/native拓扑。

文件路径按本包固定SHA核查或明确标为拟新增。执行前确认文件存在；旧文件改名时记录映射并跟随真实调用链，不创建重复模块。共享schema与symbol.ts接线由单一集成者合入。

## Interfaces

测量输出coldState=C0|C1|C2|W，dependencyPrepMs/importMs/indexBarrierMs/callerWaitMs/backendMs/cacheHit；缺值null。1.2起另记roundMode/fullReason、seedHit、fenceOrPrepareWaitMs、`index.queryCounters`差值（见[07](../docs/07-mac-performance.md)），以免把底座的全量重建或退避等待归因到本计划的代码。复用现有beginFirstTouchTrace，不新增常驻profiler。

公共预算、view/proof和状态合同继承[05](../docs/05-contracts.md)；所有测试变量如report/summary由本卡实际fixture/函数结果生成，不能硬编码成预期答案。纯断言示例在现有Node test包中落地，assert使用`node:assert/strict`。

## RED / 控制断言

assert.notEqual(c1.coldState,"C0");

assert.equal(shortCaller.timedOut,true);

对本来正确的既有行为，记录现有测试与补充边界，不修改代码强造RED。对新行为，测试应因缺失行为失败，而不是因为路径拼写/依赖装载失败。
