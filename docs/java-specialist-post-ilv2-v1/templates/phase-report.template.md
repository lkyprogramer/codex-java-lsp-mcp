# 阶段报告填写合同

此文件是格式说明，不是已通过的报告。实际报告必须给具体值或UNMEASURED及原因。

## 身份和范围

列phase、source/build/native/依赖、数据/任务/预算、机器、已安装身份；附identity文件hash。

## 触发与改动

逐任务说明做/未做原因；生产代码差异；schema/默认行为变化；未改模块。

## 验证

逐命令/测试/slot表，保留fail/skip/timeout/blocked；链接raw hash；同预算对照；区分本地fixture、真实Mac、JDT、Agent。

## 结果与限制

工程资格、质量、总成本、首次成本分别给结论；给逐任务退化；暴露holdout；任何未测项。

## 决定

ADOPT / NO_GAIN / INCONCLUSIVE / NOT_TRIGGERED；可进入下一phase的条件；生产部署需独立授权。
