## 文件与接口

修改 `src/tools/symbol.ts`、`src/mcp-server-factory.ts`、相关schema/tests；新增 `src/discovery/query.ts`（只组装index结果）；更新README工具说明；不新增公开java_context。

operation=query默认backend=static，消费DiscoveryQuery并返回docs/02契约；position/references或backend=jdt走原语义通道。outer withContext/mayStartLsp/requireLspEnabled必须与分支一致。

## 实现步骤

1. 首先写集成断言JDT_BIN=/usr/bin/false且lspEnabled=false，static query仍成功。
2. schema在query允许searchMode/terms、返回explicitname；现有source locator1-based UTF16保持。
3. 外层policy根据operation/backend计算，不能handler静态但outer先requireJdt。
4. complete/partial由索引coverage与实际查询预算决定，不由candidates非空决定。
5. 取返回locator直接喂java_impact(file,line,column)，验证不用重搜行号。
6. serializer如带preview，标previewKind=source且byte-for-byte一致；无源码preview时不声称读过。
