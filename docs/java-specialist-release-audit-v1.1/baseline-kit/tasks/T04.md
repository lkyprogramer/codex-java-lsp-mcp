消费DiscoveryQuery；产出exact或text路线及一般性scope线索。exact遵从全部输入，text即使带class name也查询相关method；同FQN无scope时不拍脑袋唯一化。

## 实现步骤

1. 先固定混合query和纯FQN回归；C2-mixed转绿，exact仍绿。
2. auto只对明确代码形状做exact：点/井号/括号，或ASCII Pascal/camel标识。纯中文自然语言及单个普通小写词默认text，避免将“结算”误识成Java变量。
3. explicit exact支持Unicode Java名称，但复杂泛型签名未支持时返回明确错误，不伪造匹配。
4. text查identifier与body/comment等有限候选并合并，不因一个type命中就返回。
5. 每个query最多6附加terms，length约束于外层schema与worker都执行。

## 关键代码/结构约束

下面是本卡需要实现的核心逻辑或结构示例，不是声称已经修改产品；需要放到所列文件并通过真实编译/集成。临时变量由当前消费者上下文提供，不能将示例当成独立可运行的完整产品补丁。

```typescript
export type QueryIntent = "exact" | "text";
export function classifyQuery(raw: string, mode: "auto"|"exact"|"text"): QueryIntent {
  const q=raw.trim();
  if (!q || q.length>512) throw new Error("query length must be 1..512");
  if (mode!=="auto") return mode;
  if (/\s/.test(q) || /[\u3400-\u9fff]/.test(q)) return "text";
  const shape=/^[A-Za-z_$][A-Za-z0-9_$]*(?:[.$][A-Za-z_$][A-Za-z0-9_$]*)*(?:#[A-Za-z_$][A-Za-z0-9_$]*(?:\([^()]*\))?)?$/;
  return shape.test(q) && (/[.#()]/.test(q) || /[A-Z]/.test(q)) ? "exact" : "text";
}
```
