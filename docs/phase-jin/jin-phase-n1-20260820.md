## 失败处置（已执行）

1. 不物化 STATEMENT / PARAMETER / LOCAL；`lexicalFingerprint` 保持空数组。
2. 增量 digest 改为运行时 xor，QUERY_GRAPH_DIGEST 不再 `JSON.stringify` 整图。
3. `readyKnowledgeGraph` 与 `snapshotDirtyRevision` 解耦，避免每次 snapshot flush 全量 rebuild。
4. 基准改为每仓独立子进程，RSS 在 coverage complete 且 `pendingBackground=0` 后取样。
5. 两措施后 RSS 仍超 → 按 N1-04 escalate（0A.4 第 4 条 (b)），**不放宽门**。

## 怎么读

1. 结构边只含 CONTAINS/DECLARES/EXTENDS/IMPLEMENTS/PERMITS/IMPORTS/ANNOTATED_WITH/MODULE_DEPENDS_ON。CALLS/CALLED_BY 与框架边归 N2a。
2. 实体 ID 形态 `path#type#member#signatureHash`（sha256[:16]）。外部类型 `ext:`。
3. 默认 `java_impact` 选择/排序未改。`QUERY_GRAPH_DIGEST` 只在 JavaIndex worker。
4. 生产 LOC 38181 → 39105（+924）。未合 `main`。
5. N2a 可在图上继续加调用/框架边，但 **N1 同口径 RSS 门会继续 FAIL**，直到修订 512 MiB 假设或压缩 JavaIndex 事实对象。下一动作等用户对 0A.4(4b) 的文档修订授权。
